# Ҳисобчи Telegram бот (фаст-фуд нуқтаси)

Овозли/матнли хабардан харажатларни ажратиб, кун/ҳафта/ой бўйича жадвал юритади.
Категориялар: **Бозорлик, Ишчилар, Ижара, Прочее**. LLM: Gemini (бепул, овозни тўғридан-тўғри тушунади).

## Ўрнатиш
1. @BotFather → `/newbot` → токенни олинг.
2. https://aistudio.google.com/apikey → бепул Gemini калит.
3. Ўз Telegram ID'нгизни @userinfobot дан билиб олинг.
4. ```bash
   cd expense-bot
   pip install -r requirements.txt
   cp .env.example .env     # токен, калит ва ID ни ёзинг
   python bot.py
   ```
Бот доим ишлаб туриши учун уни VPS/Railway/Render га қўйинг (`python bot.py` жараёни тирик турсин).

## Ишлатиш
- Овоз: «10 кг помидор 100 минг, товуқ гўшти 10 кг 350 минг, Ибрат 100 минг олди» → «Сақлаш».
- «Кеча ...» десангиз, кечаги санага ёзилади.
- `/bugun` `/kecha` `/hafta` `/oy` (`/oy 2025-10`), `/excel` — Excel (3 варақ: ҳамма қатор, кунлар кесими, ишчилар).
- `/oxirgi` → `/ochir 15` — хато ёзувни ўчириш.

Маълумотлар `expenses.db` (SQLite) да сақланади — уни вақти-вақти билан нусхалаб туринг.
