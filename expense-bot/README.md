# Ҳисобчи Telegram бот (фаст-фуд точкалари)

- **Хўжайинлар** (2-3 киши) овоз ёки матн билан харажат ва Яндекс тушумини ёзади, ходим ва кассир қўшади, ҳисобот ва Excel олади.
- **Кассирлар** ҳар куни нақд ва картага тушган савдони киритади.
- Ой охирида ҳамма нарса бир жойда кўринади: тушум (нақд, карта, Яндекс), харажат (бозорлик, ишчилар, ижара, прочее), фойда, точкалар кесими, ишчилар ойлиги.

LLM: Gemini (`gemini-flash-latest`). Овозни тўғридан-тўғри тушунади, бепул тарифи бу ҳажмга етади.

**Тўлиқ йўриқнома ва режа: [ROADMAP.md](ROADMAP.md)**

## Тез ишга тушириш
```bash
pip install -r requirements.txt
cp .env.example .env     # TELEGRAM_BOT_TOKEN, GEMINI_API_KEY, OWNER_IDS
python bot.py
```

## Файллар
| Файл | Вазифаси |
|---|---|
| `bot.py` | Telegram буйруқлари, роллар, кассир оқими, автоматик эслатмалар |
| `ai.py` | Gemini: овоз ва матндан харажат ва Яндекс тушумини ажратиш |
| `reports.py` | Ҳисобот матнлари ва Excel |
| `db.py` | SQLite база |
| `config.py` | `.env` созламалари |
| `Dockerfile`, `expense-bot.service` | Серверга қўйиш учун |
